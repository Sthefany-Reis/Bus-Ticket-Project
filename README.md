# BUS-TICKET-PROJECT

Creation of a bus booking system with a user and admin interface.
For this program to fully work, you must install matplotlib.

# Features
    - UseCase1:
      1. Creating a new file with the relevant information from the given CSV file.
      2. Checking if the updated file already exists and, if not, creating a file to store the details from the csv file.
      3. Delete the columns that are not needed.

    - UseCase2:
      1. Create signup and login functionality for both users and admins.
      2. Store user and admin credentials.
      3. Implement authentication to restrict access to certain features based on user roles.
      4. Create a user, admin and main menu for navigation.

     - UseCase3:
      1. Allow users to search ticket by category.
      2. Display ticket details. 
      3. Allow users to choose the topUp Options.
      4. Confirm the selected ticket and topUp option.
      5. Display Purchase Summary after finalising the purchases.
      6. Store purchase details in a file for the admin to access later.

     - UseCase4:
      1. Allow admin to view the topUp options available.
      2. Allow admin to change the topUp price.
      3. Store the updated topUp options in a file.
      4. Generate a Graph with purchases and quantities to the admin.
